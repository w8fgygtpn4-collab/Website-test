# Cleared — Private Pilot ACS Study

Responsive, dependency-free study website for private pilot airplane single-engine land practice. Includes 11 ACS areas, 24 original starter questions, randomized quizzes, immediate explanations and references, missed-question review, and score history.

Run `npm start` from this directory (requires Python 3). Run `npm test` to validate the question bank. Open the served site in your browser.

Progress is stored in this browser's localStorage. It does not sync across devices, and clearing browser data removes progress. No account or backend is required. An incomplete quiz updates the missed-question queue but does not record a session score.

This starter bank is a study aid, not an official FAA product or exhaustive ACS coverage. Consult the current FAA Private Pilot Airplane ACS, applicable regulations, and aircraft POH/AFM. The interface uses optional Google Fonts with local fallback fonts.
